# Broad Options Design System

## Foundations
- Primary brand colour: **#2E388D** (never replace)
- Use Material Design 3 and React Native Paper.
- 8dp spacing system.
- Cards: 16dp radius.
- Never hardcode colours; use theme tokens.

## Principles
- Progressive disclosure.
- Fast scanning over information density.
- One primary action per screen.
- Consistency over novelty.
